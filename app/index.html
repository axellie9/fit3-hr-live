ARSIP SESI PONSEL

Simpan hanya jika Anda memilih

Bukan impor riwayat gelang. Secara default tidak ada penyimpanan. Arsip hanya dibuka lewat tombol di bawah, tidak dimuat ke detak aktif.

Disimpan di browser ini, bukan brankas terenkripsi. Halaman dengan origin yang sama dapat mengaksesnya. Browser dapat menghapus arsip.

Batas & cara penyimpanan

Data kesehatan disimpan di localStorage. Jangan mengandalkannya sebagai satu-satunya salinan.

Maksimal 5 sesi, masing-masing 180 sampel terakhir (maks. 32 interval RR per sampel), dan 200.000 karakter total. Simpan berikutnya menggantikan sesi tertua jika sudah 5. Salinan identik tidak disimpan lagi. Nama/ID perangkat, paket mentah, dan diagnostik tidak diarsipkan.

Waktu sampel adalah waktu terima ponsel, bukan waktu ukur gelang. Menyimpan tidak mengubah gelang dan tidak merekam otomatis.

Terima minimal satu notifikasi di Ringkasan sebelum menyimpan.

Arsip belum dibuka. Tidak ada pemulihan data otomatis.

Arsip antarbrowser tidak dibagikan otomatis. Transfer file arsip lama belum tersedia. Ekspor di bawah hanya sesi aktif di memori, bukan cadangan arsip lama. Periksa hasil unduhan; tidak ada jaminan cadangan atau penyimpanan permanen.

Ekspor lokal (opsional)

Unduh JSON berisi sampel sesi di memori dan diagnostik. Ini data kesehatan; nama/ID perangkat tidak disertakan. Tidak ada unggahan. File hasil unduh berada di luar kontrol halaman ini.

SUMBER & AKSES

Perangkat

Bluetooth HRS

Layanan 180D / karakteristik 2A37. Hanya menerima notifikasi; tidak mengubah pengaturan atau riwayat gelang.

Membuka di Bluefy pada iPhone
  1. Salin alamat halaman ini.
  2. Buka aplikasi Bluefy, lalu tempel alamat di bilah alamatnya. Gunakan versi HTTPS.
  3. Izinkan Bluetooth untuk Bluefy di pengaturan iOS. Dekatkan gelang, kembali ke Ringkasan, lalu pilih & hubungkan.
  4. Cocokkan perangkat dengan layar gelang. Jika gagal, coba lagi tanpa reset atau perubahan firmware.

Safari tidak menyediakan Web Bluetooth untuk halaman ini. Tidak ada pengalihan aplikasi otomatis.

Tampilan offline

Offline belum siap; memeriksa dukungan browser.

Tidak ada muat ulang otomatis. Muat ulang menghapus sesi aktif di memori; ekspor dahulu.

Pemasangan ikon, cache offline, dan Web Bluetooth adalah kemampuan berbeda. Tidak ada sinkronisasi otomatis atau rekaman latar.

Pasang tampilan di layar utama iPhone
  1. Buka alamat HTTPS ini di Safari.
  2. Buka menu Bagikan, pilih Add to Home Screen / Tambah ke Layar Utama, lalu Tambah. Menu dapat berbeda menurut versi iOS.
  3. Buka ikon untuk tampilan mandiri. Jika menu tidak ada, gunakan halaman browser biasa.

Memasang ikon tidak menambah Web Bluetooth. Tampilan mandiri mungkin tanpa Bluetooth; gunakan Bluefy untuk HRS bila API tersedia.

Penyimpanan Safari, layar utama, dan Bluefy dapat terpisah. Arsip tidak dibagikan otomatis. Offline hanya untuk tampilan aplikasi setelah cache berhasil, bukan rekaman Bluetooth latar.
